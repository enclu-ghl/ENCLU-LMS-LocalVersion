# 마이그레이션 계획

범위: 웹 대시보드(Streamlit app.py) + Supabase/원격 Postgres 데이터 파이프라인을 IDC Linux 서버로 이전. (Tkinter 데스크톱 도구 4종과 WMS 로그인 자동화는 별도 트랙 — §10 확인 후 범위 확정)

모든 명령은 "실행 예정"이며, 실제 실행 전 단계별 승인이 필요합니다.

---

### 1. 기존 환경 전체 백업
- 사전조건: 없음 (읽기 전용)
- 실행 예정 명령: `robocopy "통합시스템" "백업위치" /MIR /XD __pycache__ venv` (원본 미변경, 사본만 생성)
- 예상 영향: 없음 (신규 파일만 생성)
- 확인 기준: 백업 폴더 파일 수/용량이 원본과 일치
- 중단 기준: 백업 대상 디스크 여유공간 부족
- 롤백: 백업 폴더 삭제만 하면 됨 (원본 무영향)

### 2. DB 백업 및 복구 테스트
- 사전조건: Supabase/원격 Postgres 접속 정보 확보(승인된 방식으로만 조회)
- 실행 예정 명령: `pg_dump`로 각 DB 덤프 후, 별도 테스트 DB에 `pg_restore`로 복원 검증
- 예상 영향: 원본 DB 무변경(읽기 전용 덤프)
- 확인 기준: 복원된 테스트 DB의 테이블/행 수가 원본과 일치
- 중단 기준: 덤프 중 원본 DB 부하 급증 시
- 롤백: 테스트 DB 폐기

### 3. 파일과 데이터 무결성 확인
- 사전조건: 1,2단계 완료
- 실행 예정 명령: 백업본 체크섬(sha256) 비교
- 예상 영향: 없음
- 확인 기준: 체크섬 일치
- 중단 기준: 불일치 항목 존재
- 롤백: 해당 없음 (조사 단계)

### 4. 신규 IDC 서버 사전 점검
- 사전조건: IDC 서버 프로비저닝 및 접속 정보 수령 (승인 필요 항목)
- 실행 예정 명령: OS 버전/커널/디스크/네트워크 경로(WMS·Supabase·원격Postgres 도달 가능 여부) 점검
- 예상 영향: 없음 (신규 서버, 아직 운영 미투입)
- 확인 기준: 필요한 아웃바운드 목적지 전부 도달 가능
- 중단 기준: 필수 목적지(Supabase 등) 도달 불가
- 롤백: 해당 없음

### 5. 운영환경 재현
- 사전조건: 4단계 완료
- 실행 예정 명령: Docker/systemd, 리버스프록시, 방화벽 규칙 구성 (§IDC_NETWORK_SECURITY_PLAN.md)
- 예상 영향: 신규 서버에만 적용, 기존 Windows 운영 무영향
- 확인 기준: 헬스체크 통과
- 중단 기준: 구성 실패
- 롤백: 신규 서버 재구성 또는 폐기, 기존 Windows 환경은 그대로 유지되어 있으므로 서비스 영향 없음

### 6. 애플리케이션 스테이징 배포
- 사전조건: 5단계 완료, 하드코딩 경로 제거된 코드 사본 준비
- 실행 예정 명령: 코드 배포, `.env` 반영(값은 승인된 채널로만 전달)
- 예상 영향: 스테이징 한정, 운영 서비스 무영향
- 확인 기준: 앱 기동 성공, 로그 오류 없음
- 중단 기준: 기동 실패
- 롤백: 컨테이너/서비스 중지

### 7. DB 및 파일 1차 이전
- 사전조건: 6단계 완료
- 실행 예정 명령: 테스트 DB로 pg_dump/restore, 파일 동기화(운영 원본은 계속 유지, 사본만 이전)
- 예상 영향: 원본 무변경
- 확인 기준: 데이터 건수/샘플 비교 일치
- 중단 기준: 데이터 불일치
- 롤백: 스테이징 DB/파일 폐기

### 8. 기능·권한·연동·성능 테스트
- 사전조건: 7단계 완료
- 실행 예정 명령: §TEST_CHECKLIST.md 항목 실행
- 예상 영향: 스테이징 한정
- 확인 기준: 체크리스트 전항목 통과
- 중단 기준: 크리티컬 결함 발견
- 롤백: 해당 없음(스테이징)

### 9. SCM팀 사용자 테스트 (UAT)
- 사전조건: 8단계 통과
- 실행 예정 명령: 실제 사용자(창고/본사) 대상 스테이징 URL 공유, 피드백 수집
- 예상 영향: 없음 (운영 서비스는 여전히 기존 환경)
- 확인 기준: 사용자 승인
- 중단 기준: 주요 기능 불만족
- 롤백: 해당 없음

### 10. 변경 동결 (Change Freeze)
- 사전조건: UAT 통과
- 실행 예정 명령: 기존 운영 환경에 대한 코드/설정 변경 중단 공지
- 예상 영향: 신규 기능 반영 일시 중단
- 확인 기준: 팀 공지 완료
- 중단 기준: 없음
- 롤백: 동결 해제 공지

### 11. 최종 DB와 변경 파일 이전
- 사전조건: 10단계, 동결 기간 중 실행
- 실행 예정 명령: 최종 pg_dump/restore, 최신 파일 동기화 (**승인 필요 — 운영 데이터 대상**)
- 예상 영향: 짧은 다운타임 가능
- 확인 기준: 최종 데이터 일치 확인
- 중단 기준: 이전 중 오류 발생
- 롤백: 기존 Windows 환경 그대로 서비스 지속(전환 전이므로 무중단)

### 12. 서비스 전환 (Cutover)
- 사전조건: 11단계 완료
- 실행 예정 명령: DNS/리버스프록시를 IDC 신규 서버로 전환 (**승인 필요**)
- 예상 영향: 사용자가 신규 서버로 접속 시작
- 확인 기준: 정상 접속·핵심 기능 확인
- 중단 기준: 전환 직후 장애 발생
- 롤백: §CUTOVER_ROLLBACK_RUNBOOK.md 절차대로 기존 Windows 11 환경으로 즉시 복귀

### 13. 모니터링
- 사전조건: 12단계 완료
- 실행 예정 명령: 전환 후 24~72시간 집중 모니터링
- 예상 영향: 없음(관찰만)
- 확인 기준: 오류율/성능 지표 정상
- 중단 기준: 임계치 초과
- 롤백: 필요 시 12단계 롤백 절차 발동

### 14. 문제 발생 시 기존 Windows 11 환경으로 원복
- §CUTOVER_ROLLBACK_RUNBOOK.md 참조. 원칙적으로 기존 Windows 환경은 전환 후 일정 기간 그대로 보존(삭제하지 않음)하여 즉시 원복 가능한 상태를 유지

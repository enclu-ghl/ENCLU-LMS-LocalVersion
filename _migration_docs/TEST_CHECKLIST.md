# 테스트 체크리스트 (스테이징 환경 기준)

## 기능
- [ ] 웹 대시보드(재고조사/무게구간계산/UPH현황판) 3개 쿼리파라미터 전부 정상 로딩
- [ ] 바코드 인식(streamlit-webrtc + pyzbar) 브라우저 웹캠에서 정상 동작
- [ ] Supabase 연동 데이터 조회/저장 정상
- [ ] 원격 PostgreSQL(박스추천 관련 데이터) 조회 정상 — 단, 박스추천 자체는 데스크톱 앱이므로 DB 레벨 연결 테스트로 한정
- [ ] UPH watchdog가 신규 파일 감지 → DB 반영까지 파이프라인 동작 확인

## 권한
- [ ] 신규 서버 서비스 계정이 최소 권한(DB 애플리케이션 계정, sudo 불필요)으로만 동작하는지 확인
- [ ] 관리 포트(SSH 등)가 VPN 대역 외부에서 접근 불가한지 확인

## 연동
- [ ] IDC → Supabase 아웃바운드 연결 확인
- [ ] IDC → 원격 PostgreSQL 아웃바운드 연결 확인 (호스트 위치 확정 후)
- [ ] IDC → WMS(이지어드민) 연결 필요 여부 및 가능 여부 확인 (파이프라인 이전 범위에 포함될 경우)

## 성능
- [ ] 동시 사용자 다수 접속 시 응답 시간 측정
- [ ] 대시보드 새로고침(streamlit-autorefresh) 주기 하에서 서버 부하 확인

## 보안
- [ ] HTTPS 인증서 정상 적용, HTTP→HTTPS 리다이렉트 확인
- [ ] 방화벽 정책(§IDC_NETWORK_SECURITY_PLAN.md) 적용 후 불필요 포트 전부 닫혀있는지 외부 스캔으로 확인
- [ ] DB 계정 비밀번호가 소스코드가 아닌 환경변수/시크릿 매니저에서만 로드되는지 코드 검토로 확인

## 데이터 무결성
- [ ] 이전된 DB 레코드 건수/샘플 값이 원본과 일치
- [ ] 이전된 파일(다운로드 캐시 등) 체크섬 일치

## 사용자 인수(UAT)
- [ ] 창고 담당자 시나리오 테스트 통과
- [ ] 본사 담당자 시나리오 테스트 통과
- [ ] 장애/에러 메시지가 사용자에게 명확히 노출되는지 확인

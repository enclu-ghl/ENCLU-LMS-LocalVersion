# ENCLU SCM — 새 PC 설치 가이드

새 컴퓨터에서 통합 시스템을 쓸 때 필요한 준비를 정리한 문서다.

프로그램이 자동으로 해주는 것과, **사람이 직접 해줘야만 하는 것**을 구분해 적었다.
자동화할 수 없는 항목(크롬 다운로드 위치, WMS 로그인 등)은 브라우저 설정이나
계정에 묶여 있어서 코드로 강제할 수 없다.

---

## 0. 먼저 — 어떤 용도의 PC인가

프로그램마다 필요한 준비가 다르다. 해당하는 절만 하면 된다.

| 용도 | 필요한 설치 절차 |
|---|---|
| 웹 3종만 사용 (재고조사 / 무게구간 / UPH 현황판) | **1번만** |
| 파일 찢기, 박스크기추천도 사용 | 1 + 2 |
| 상품 매칭 매크로도 사용 | 1 + 2 + 3 |
| **UPH 자동 제어판 운영** (지정 PC 1대) | 1 + 2 + 3 + 4 |

> ⚠️ **UPH 자동 제어판은 한 대에서만 돌려야 한다.**
> 여러 PC에서 동시에 돌리면 같은 WMS 파일을 각자 읽어 DB에 중복 반영된다.

---

## 1. 프로그램 설치 (모든 PC 공통)

1. 아래에서 `ENCLU_SCM.exe` 를 받는다. (Source code zip / tar.gz 는 받지 않는다)

   https://github.com/enclu-ghl/ENCLU-LMS-LocalVersion/releases/latest

2. `C:\ENCLU_SCM\` 폴더를 만들고 그 안에 넣는다.

   - `C:\Program Files\` 안에는 두지 않는다 — 권한 때문에 자동 업데이트가 막힌다.
   - 다운로드 폴더에서 바로 실행하지 않는다 — 파일이 정리되며 사라질 수 있다.

3. 실행한다. "Windows의 PC를 보호했습니다" 파란 경고가 뜨면
   **추가 정보 → 실행**. 사내 제작 프로그램이라 인증서가 없어서 뜨는 정상 경고다.

4. 첫 실행 시 초기 설정 창에서 다운로드 폴더 / 저장 폴더 / 테마를 정한다.

설치 후 폴더 모습:

```
C:\ENCLU_SCM\
  ├─ ENCLU_SCM.exe      ← 배포 파일
  ├─ config.json        ← 자동 생성 (설정)
  ├─ credentials.dat    ← 자동 생성 (DB 접속정보, 이 PC에서만 복호화됨)
  ├─ version.txt        ← 자동 생성
  └─ data\              ← 자동 생성 (UPH 로그·캐시)
```

**업데이트는 자동이다.** 새 버전이 나오면 프로그램을 켤 때 안내창이 뜬다.
설정과 접속정보는 업데이트해도 유지된다.

---

## 2. DB 접속정보 입력

파일 찢기와 박스크기추천은 데이터베이스를 쓴다.
처음 열 때 입력창이 뜨며, **한 번만** 입력하면 된다.

| 프로그램 | 입력 항목 |
|---|---|
| 파일 찢기 | Supabase 접속 URL |
| 박스크기추천 | DB 호스트 / 포트 / 이름 / 계정 / 비밀번호 |

값은 관리자에게 받는다. **프로그램 안에는 들어있지 않다** — exe가 공개 저장소에
올라가기 때문에 접속정보를 넣으면 그대로 공개되기 때문이다.

입력한 값은 `credentials.dat` 에 Windows 계정 단위로 암호화되어 저장된다.
이 파일을 다른 PC에 복사해도 열리지 않는다.

> 값을 잘못 넣었다면 `credentials.dat` 를 지우고 다시 실행하면 입력창이 다시 뜬다.

상품 매칭 매크로와 UPH 제어판은 DB를 쓰지 않아 입력창이 뜨지 않는다.

---

## 3. 디버그 크롬 준비 (매크로 사용 PC)

상품 매칭 매크로와 UPH 다운로드 매크로는 **디버그 모드로 열린 크롬**에 붙어서
동작한다. 사람이 로그인해둔 세션을 그대로 쓰기 위한 방식이라, 크롬을 이 방식으로
띄워두지 않으면 매크로가 붙을 대상이 없다.

### 3-1. 크롬 설치 확인

프로그램은 아래 순서로 크롬을 찾는다. 기본 위치에 설치돼 있으면 그대로 두면 된다.

```
C:\Program Files\Google\Chrome\Application\chrome.exe
C:\Program Files (x86)\Google\Chrome\Application\chrome.exe
%LOCALAPPDATA%\Google\Chrome\Application\chrome.exe
```

### 3-2. 디버그 크롬 실행

프로그램 안의 **Chrome 실행** 버튼을 쓰면 아래와 동일하게 뜬다.

```
chrome.exe --remote-debugging-port=9222 --user-data-dir=C:\chrome-debug-profile
```

- `C:\chrome-debug-profile` 은 **평소 쓰는 크롬과 분리된 전용 프로필**이다.
  처음 열면 로그인 정보가 없는 새 크롬처럼 보이는 게 정상이다.
- 이 프로필에서 **이지어드민에 로그인해두면** 그 상태가 계속 유지된다.
- 평소 쓰는 크롬 창은 별개로 열어도 상관없다.

### 3-3. ⚠️ 크롬 다운로드 위치 지정 (반드시 수동)

**이 항목이 자동화가 안 되는 부분이다.** 크롬 프로필 설정이라 프로그램이
대신 바꿔줄 수 없다. 이걸 빼먹으면 매크로는 정상 동작하는데 파일이
엉뚱한 곳에 떨어져서 watchdog이 아무것도 못 읽는다.

디버그 크롬 창에서:

1. 주소창에 `chrome://settings/downloads` 입력
2. **위치**를 `C:\ENCLU\WMS_다운로드` 로 변경
3. **다운로드 전에 각 파일의 저장 위치 확인** 을 **끔**
   (켜져 있으면 매번 저장 대화상자가 떠서 매크로가 멈춘다)

> 감시 폴더를 다른 위치로 쓰고 싶으면 환경변수 `UPH_WATCH_FOLDER` 를 지정하고,
> 크롬 다운로드 위치도 같은 곳으로 맞춘다. **두 값이 반드시 일치해야 한다.**

---

## 4. UPH 자동 제어판 (지정 PC 1대만)

### 4-1. 감시 폴더

`C:\ENCLU\WMS_다운로드` 는 watchdog이 처음 시작할 때 **자동으로 만든다.**
로그에 아래 줄이 보이면 정상이다.

```
[INFO] 감시 폴더를 새로 만들었습니다: C:\ENCLU\WMS_다운로드
```

> 프로그램 폴더(`C:\ENCLU_SCM\`)가 아니라 **`C:\ENCLU\`** 밑에 생긴다.
> 탐색기에서 안 보인다면 경로를 헷갈린 것이다.

### 4-2. WMS 계정

다운로드 매크로는 다운로드 관리자 목록의 **맨 위 행**을 자기 요청으로 간주한다.
그래서 **이 매크로 전용 WMS 계정**을 써야 한다.
사람이 같이 쓰는 계정으로 돌리면 다른 사람의 다운로드 요청을 자기 것으로
착각해 엉뚱한 파일을 받는다.

### 4-3. 실행 순서

1. UPH 자동 제어판 실행 → 비밀번호 입력
2. **Chrome 실행** → 디버그 크롬에서 이지어드민 로그인 (3-2, 3-3 완료 상태여야 함)
3. **watchdog_agent 시작** — 폴더를 감시하며 DB에 반영
4. **uph_download_macro 시작** — 주기적으로 WMS에서 파일을 받아옴

로그는 `C:\ENCLU_SCM\data\` 에 쌓인다.

### 4-4. 중복 실행 금지

두 대 이상에서 watchdog을 돌리면 같은 파일을 각자 읽어 DB에 중복 반영된다.
운영 PC를 옮길 때는 **기존 PC에서 먼저 중지한 뒤** 새 PC에서 시작한다.

## 5. 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| 카드가 "미설치"로 표시됨 | 개발 PC가 아닌데 프로그램 폴더를 찾는 경우. 최신 버전으로 업데이트 |
| 파일 찢기에서 브랜드 목록이 비어 있음 | DB 접속정보 오입력. `credentials.dat` 삭제 후 재입력 |
| 박스추천에서 "연결할 수 없습니다" | DB 호스트/포트 확인. 사내망 접속 여부 확인 |
| 매크로가 크롬을 못 찾음 | 3-1의 경로에 크롬이 있는지 확인 |
| 매크로가 시작은 되는데 아무 일도 안 함 | 디버그 크롬이 떠 있는지, 이지어드민에 로그인돼 있는지 |
| **watchdog이 도는데 DB가 안 바뀜** | **3-3 크롬 다운로드 위치가 감시 폴더와 다른 경우가 대부분** |
| 업데이트를 눌렀는데 안 됨 | `C:\ENCLU_SCM\enclu_update_error.log` 확인 |

로그 위치:

```
C:\ENCLU_SCM\data\uph_agent.log            watchdog
C:\ENCLU_SCM\data\uph_download_macro.log   다운로드 매크로
C:\ENCLU_SCM\enclu_update_error.log        업데이트 실패 시에만 생성
```

# 보고서 양식

## 기획/개선 보고서 (5항목)
```
기획안에 관하여 아래와 같이 상신드리오니, 검토 요청드립니다.
----- 아 래 -----
1. 개요
2. 주제
3. 상세 내용   ← 문제·근거·대안·권고안·실행 일정
4. 목표        ← 측정 기준·측정 기간
5. 예산(안)    ← 자원·비용
```

## 구매 상신 (6항목)
```
1. 내용
2. 거래처 혹은 구매 링크
3. 금액(부가세 포함 여부)
4. 계좌 혹은 카드 결제 여부
5. 지급일
6. 기타 상세 사항
```

## 일일 보고
수행 업무 / 실적(기간·단위·산식 명시) / 특이사항 / 미완료·다음 일정

## 주간 보고
주간 실적 / 전주 비교(동일 기간·기준) / 반복 이슈 / 차주 계획

## 부재 보고
일시 / 사유 / 업무 영향 / 인수인계 / 복귀 일정

## 팀원 입력 공통 양식
```
[업무 유형] 데이터 분석 / 현황 보고 / 개선안 / 구매 / 부재 / 일일 / 주간
[목적]
[기간·기준일]
[첨부 자료] 파일명, 시트명, 원천 시스템
[지표 정의] 건수/수량/금액/시간, 취소·중복·보류 제외 기준
[확인한 사실]
[현재 문제 또는 질문]
[비교 기준] 전주·전월·목표 등
[원하는 결과]
[제약] 예산·인력·마감·변경 불가 조건
부족한 정보는 3~5개씩 질문하고, 먼저 초안을 보여줘.
```

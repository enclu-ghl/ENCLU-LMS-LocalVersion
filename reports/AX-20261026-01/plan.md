# AX-20261026-01 — 웹앱(PWA) 전체 디자인 개편 "창고 구역 표지판" (Claude 직접, 디자인 스킬 기반)

## 요청
설치한 디자인 스킬(Impeccable·taste·Emil Kowalski)로 현재 웹앱을 평가하고, 가능하면 전체 디자인 틀을 바꾼다. 웹·앱(PWA) 모두 반응형.

## 평가 결과 (Impeccable 업무 화면 기준)
1. 본문 폭 640px 고정 + 둥근 "휴대폰 모형" 틀 → PC에서 화면 절반 이상 빈 공간
2. 메뉴·제목·지표·버튼·알림에 이모지를 아이콘 대신 사용
3. 보라·파랑 그라데이션 카드, 반투명 유리, 그라데이션 글자 (AI 기본 패턴)
4. 지표 카드 정렬·숫자 폭 불일치, 강조색 과다

## 변경 (화면 계층만 — 기능·계산·메뉴 문자열·분기 로직 변경 없음)
- `_PALETTE` 교체: 콘크리트 회색 작업면 + 남색 사이드바 레일(두 모드 공통) + 주요 동작 파랑(#2563eb, 흰 글자 5.2:1) + 선택 표시 안전선 노랑. 그라데이션 색(accent1/2)은 같은 파랑으로 단색화
- 전역 CSS 재작성: 폭 최대 1280px(휴대폰 640px 이하 한 열), 둥근 틀 제거, 버튼·입력·선택·업로더·탭·알림·표 일관 스타일, 포커스 표시, 같은 폭 숫자, 동작 줄이기 설정 존중
- 사이드바: 라디오 동그라미 숨기고 내비게이션 줄 + 선택 노랑 막대, `format_func`로 Material 아이콘 표시(내부 메뉴 값은 그대로), UPH 동 메뉴는 동별 구역색 점
- 허브: 그라데이션 카드 → 단색 카드 + Material 아이콘, UPH 카드에 A·B·F 구역색 띠, DB 카드에 상태색 점, 날짜 표시
- 동별 화면: 제목 위 구역 표지(동 이름 표 + 구역색 띠)
- 이모지 제거: 제목(st.title 20·subheader 7), 지표 이름 5, 펼침 21, 버튼 85개는 `icon=` Material 아이콘으로, 알림 89개는 `icon=`, 인원 관리 패널 라벨 HTML 아이콘
- `.streamlit/config.toml` 팔레트·모서리 반경 갱신
- 재고 스캔 상품 카드의 굵은 왼쪽 색 테두리 제거

## 검증
- 별도 시험 서버(127.0.0.1:8502)에서 기기 라이트·다크 각각 6개 시스템 25개 메뉴 + 허브 자동 순회: 글자 대비 3:1 미만 0건, 화면 예외 0건
- PC(1280/1440)·휴대폰(375) 화면 확인, 휴대폰 사이드바 메뉴 확인
- `py -B -m unittest discover -s tests` 통과
- 미검증: 실제 직원 휴대폰, 키오스크(모니터 표시 모드)는 기존 디자인 유지, 이모지가 남은 일부 캡션·HTML 안내문

## 추가 (사용자 요청, 같은 작업)
- UPH 전체 현황에 **동별 진행 게이지**: A·B·F동마다 전체(완료+잔여)·완료·잔여·진행률(오늘 완료 ÷ (완료 + 잔여)) 막대, 금일 외 잔여·보류가 있으면 아래 표시. 숫자는 동별 화면과 같은 `uph_get_order_counts` 결과를 재사용(전체 화면 계산 루프에서 이미 조회하던 값을 보관만 함, 추가 쿼리 없음). 조회 실패한 동은 0으로 그리지 않고 "조회 실패".
- 확인: A+B+F 완료 합(325+887+180=1,392) = 전체 완료(배송) 1,392. 라이트·다크·휴대폰 화면, 대비 검사 통과.
- 정리: DB 용량 배너의 빈 문자열 연결(`"" + msg`)을 `msg` + 아이콘으로.

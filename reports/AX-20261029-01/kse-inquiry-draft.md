# KSE 기술지원 문의 초안 (2026-10-30 작성, 미발송)

받는 곳: KSE 기술지원팀 (API 가이드에 안내된 기술지원 메일)
발송: 사용자가 직접. 계정 ID·API 키는 메일에 적지 않는다.

제목: [엔클루] KSE OMS API 연동 관련 문의 (배송등록·라벨·사은품)

안녕하세요, 엔클루 SCM팀입니다.
현재 KSE OMS 화면에서 파일 업로드로 배송접수하고 송장(L10, 90×60)을 출력하고 있으며,
자체 시스템에서 API(createOrders / getOrders)로 배송등록하고 라벨을 직접 출력하는 방식으로 전환을 검토 중입니다.
아래 사항 확인 부탁드립니다.

1. **사은품(기프트) 처리**
   현재 OMS 업로드 시 KSE 측에서 기프트 처리된 상품이 목록에 `gift` 행으로 추가되고 있습니다.
   API(createOrders)로 등록하는 경우에도 동일하게 기프트가 자동 추가되나요?
   아니면 요청 시 GoodsList에 `ItemType=gift` 행을 저희가 직접 넣어야 하나요?

2. **자체 출력 라벨 사용 가능 여부**
   OMS에서 출력하는 L10 라벨 대신, 저희 시스템에서 동일 정보(배송등록번호 CODE128 바코드 등)로 만든 라벨을 부착해도 입고 처리에 문제가 없나요?
   라벨에 반드시 들어가야 하는 항목, 바코드 규격(종류·최소 크기), 라벨 우측의 `L10-3` 같은 표기의 의미를 알려 주세요.

3. **OMS에서 삭제한 배송건 조회**
   OMS 화면에서 삭제한 배송등록번호를 getOrders로 조회하면 어떤 응답(코드)이 반환되나요?
   삭제 후 같은 장바구니번호(PackageNo)로 다시 등록할 수 있나요? (9903014 중복 오류 여부)

4. **배송서비스 변경**
   물량이 많을 때 일괄 `KSE Light`로 접수하는 경우가 있습니다. 규격 초과 건이 `KSE`로 변경되면
   배송등록번호(TrackingNo)가 바뀌나요, 그대로인가요? 변경 사실을 API로 확인할 수 있는 방법(getOrders·CS 조회 등)이 있나요?

5. **무게(RealWeight) 필수값**
   입고 시 재측정된다고 안내되어 있는데, 등록 시 기본값(예: 0.1kg 등)으로 넣어도 되나요?

6. **브랜드별 계정·테스트서버**
   브랜드별로 셀러 계정이 나뉘어 있어 계정마다 API 키를 발급받아 사용할 예정입니다. 테스트서버도 계정마다 따로 가입해야 하나요?

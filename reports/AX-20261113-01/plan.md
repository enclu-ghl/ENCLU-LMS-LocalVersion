# AX-20261113-01 UPH 출고동 A/B/F → B/D/F (긴급, Claude 작성)

> 사용자 요청(2026-11-13): 물류 개편으로 A동은 적치동, 출고동은 B·D·F동.
> UPH에서 A동을 빼고 D동으로. 비디비치·아리얼·믁끄럽·유니딧 → D동, 스타일셀러 → F동, 이벤트 → B동.
> (A동 업체 피킹존 변경·재고할당 반영은 현장에서 별도 진행 예정 — 이번 범위 아님)
> 긴급 요청이라 Codex 지시서 없이 Claude가 바로 구현했다 — 이 문서는 검토용 요약이다.

## 원래 동작
- UPH 동별 현황 메뉴가 `'🔴 A동 현황'·'🔵 B동 현황'·'🟢 F동 현황'` 고정 문자열, 분기·사이드바 색·허브 카드도 A/B/F 고정.
- 판매처→동은 `sales_channel_dong_mapping`, 수집기(watchdog)가 5분마다 읽어 `order_status_log.dong`에 기록.
  상태가 바뀐 행만 다시 쓰므로, 매핑을 바꿔도 이미 기록된 미배송 행의 동은 그대로.

## 변경
### 운영 DB (`migration_dong_bdf.sql`, pg_dump + CSV 백업 후 적용)
1. `uph_dong_code`: D동 추가(🟠 #e8833a, sort 25 → B·D·F 순), A동 `is_active=false`(과거 실적 FK 때문에 행 유지).
2. 매핑: 스타일셀러→F동, 이벤트-엔클루→B동, 나머지 A동 판매처 10개→D동.
3. `order_status_log`: 같은 송장번호에 배송 행이 하나도 없는 A동 행 587행(비디비치 110송장·아리얼 1송장)을 새 매핑 동으로.
   배송된 주문(과거 실적)은 A동 그대로.

### 웹 `app.py`
- `load_dong_codes(table, include_inactive=False)`. `DONG_LIST`=활성(B/D/F), `DONG_LIST_ALL`=비활성 포함(+A동).
- 동별 현황 메뉴를 `UPH_DONG_MENUS = {f"{emoji} {동} 현황": 동}`로 생성 → 사이드바·분기·메뉴 점 색 CSS·허브 카드 문구/색 막대 모두 `DONG_LIST`에서.
  (DECISIONS의 "메뉴 문자열 고정"을 UPH 동 메뉴에 한해 바꿈: 동이 바뀔 때 코드 수정 없이 표만 고치면 되도록)
- 지난 동이 필요한 곳은 `DONG_LIST_ALL`: 다운로드 및 분석 대상·일자별 UPH·동별 시트, 과거 데이터 입력 검증·삭제, 데이터 정정의 동 선택.
- 판매처 매핑 관리: 비활성 동에 매핑이 남으면 그 탭도 보여 줌(옮길 수 있게).
- 표를 못 읽을 때 기본값 B/D/F(+A동 과거용), `DONG_META`에 D동 기본 색.

## 검토 요청 포인트
- 송장 단위 판정으로 옮긴 범위가 맞는지(부분 배송·0패딩 order_key 등)
- 메뉴 생성 방식에서 세션에 남은 예전 메뉴 값·키오스크 키 문제
- 전체 현황의 오늘 UPH: A동은 활성 목록에서 빠져 오늘(11-13) A동 인시·완료가 전체 UPH에서 제외됨

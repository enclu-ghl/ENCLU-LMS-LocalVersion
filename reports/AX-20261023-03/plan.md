## 사용자 확정 업무 기준 (10/23)
1. 정책 무관 수정 + 푸시 진행
2. 같은 세션·바코드·로케이션·유통기한 기준행 중복 → **업로드 오류로 차단**
3. 간단조사 → **상품·로케이션 총량만 저장(유통기한 미확인)**, 리포트도 총량 비교
4. 동시 저장 → **충돌 알림 후 재확인**
5. 같은 세션명 재업로드 → **새 회차** (실사 있는 세션 덮어쓰기 금지)
6. 권한 → 지금은 로그인 없음(웹앱 전체 로그인은 별건). 삭제 버튼에는 확인 체크만 추가

## 수정 내역 (감사 번호)
- F01 간단조사 총량 1행 저장(초과분 소실 해결), 리포트 총량 비교
- F02 유통기한 없음(NULL) 실사를 정상 키로 비교
- F03 리포트 키에 세션 포함, '전체'에서 세션 컬럼 표시, 담당작업자 결합도 세션 포함
- F04 업로드 중복 차단(파일 안 + 기존 세션과 겹침), 기존 중복 데이터는 리포트에서 합산·표시, 홈 진행률·조사 로그의 중복 계산 제거
- F05 전수조사 같은 날짜 합산, 기존값 미리 채우기는 첫 행만
- F06 처음 띄운 시점 대비 변경을 화면에서 알리고, 저장 직전 잠금 안에서 다시 비교(충돌이면 저장 안 함)
- F07 저장·분할·변경·재정렬 공통 잠금 키, 잠금 후 원본 재조회(분할 잔량, 재정렬 합계)
- F09 다중 로케이션 바코드는 위치 선택 강제, 입력 위치에 기준이 없으면 다른 위치 수량을 빌려오지 않음
- F10 위젯 키에 세션·바코드·위치 포함
- F11 업로드 문자열로 읽기(앞자리 0 보존), 필수값·정수·음수 검증, 오류 있으면 전체 차단, '옵션' 미저장 안내(DB 칸 없음)
- F12 유통기한 실제 달력 검증(업로드·분할·변경·재정렬·추가), 잘못된 추가 유통기한이 있으면 저장 차단
- F14 실사 있는 세션 덮어쓰기 차단, 새 세션명 안내
- F15 브라우저 전용 세션 메모임을 안내
- F16 오류 스캔은 세션 정보가 없어 필터 불가임을 표시 (컬럼 추가는 스키마 변경이라 별건)
- F17 저장 실패 시 저장 버튼 잠김 해제(finally)
- F18 조사 로그가 최종 상태만 보여줌을 안내 (변경 이력은 별건)
- F21 상품명·세션명 등 HTML 삽입 이스케이프
- F22 Excel 시트명 금지문자·길이·중복 처리
- F23 허브 건수 조회 실패를 0건과 구분(롤백 후 '조회 실패' 표시)
- F13 일부: 전체 삭제·기준재고 삭제에 확인 체크(로그인은 별건)

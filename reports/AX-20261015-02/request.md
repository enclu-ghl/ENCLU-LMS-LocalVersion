문제: UPH 현황판에서 uph_get_order_counts() 예외를 except Exception 으로 삼키고 수치를 0으로 대체(3544-3547, 3563-3567) — DB 장애가 "0건"으로 보이고, 전체 화면에서 실패한 동이 완료 0건으로 UPH 계산에 들어가 UPH가 낮아짐.
요구:
1. 조회 실패를 화면에서 알아볼 수 있게 (일반 모드와 모니터/키오스크 모드 모두)
2. 예외를 로그로 남김
3. 전체 화면 UPH 계산에서 조회 실패한 동은 분자·분모에서 제외
4. 정상 동작(조회 성공) 시 화면·수치 변화 없음
5. 운영 중인 파일이므로 최소 변경, 테스트 방법 포함
counts 값이 화면 어디서 쓰이는지(포맷팅 :, 등) 확인해서 "-" 표시가 가능한지, 아니면 0 유지 + 경고 표시가 안전한지 판단해 줘.

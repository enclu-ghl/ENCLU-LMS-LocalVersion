# AX-20261027-02 — UPH 모니터 표시 모드(TV) 디자인 맞추기 (Claude 직접)

## 요청
10/26 웹앱 개편("창고 구역 표지판")에서 빠진 모니터 표시 모드(키오스크, 현장 TV)를 같은 디자인으로.

## 변경 (화면 계층 — 휴식·재시작·마감 버튼 동작, 조회, 계산 변경 없음)
- 그라데이션 큰 카드·이모지 아이콘·파란 전체화면 버튼 제거
- 상단: 동 구역 표지(동별 화면) + "○○ 현황판" + 상태 표시(상태색 점: 진행=동 색, 휴식=주황, 마감=초록) + 큰 실시간 시계
- 진행률: 큰 퍼센트(4.2rem) + 동 색 게이지 + "완료 / 대상" (산식 그대로: 완료 ÷ (오늘 대기 + 금일 외 잔여))
- 지표 6칸: 큰 같은 폭 숫자, 보류 > 0이면 경고 색, 실시간 UPH 칸은 동 색 테두리
- 전체 현황 TV에도 A·B·F 동별 게이지 — 일반 화면과 같은 `dong_gauge_html()`로 통일(일반 화면 인라인 코드를 함수로 추출)
- 최근 완료 처리 내역: 하나의 카드(예전엔 여는/닫는 div가 따로 렌더링돼 카드로 감싸지지 않았음), 상품명 HTML 이스케이프, 전체 화면에서는 동 표지
- **버그 수정**: 최근 완료 시각이 UTC로 표시되던 문제(02:34 → 11:34) — timestamptz를 Asia/Seoul로 변환
- 전체화면 버튼(iframe): 앱 버튼과 같은 모양, 라이트/다크 대응

# AX-20261121-01 재고할당 '주의' 표시 (행사 기간 로케이션 겹침)

## 요청 (사용자, 2026-11-21)
행사 기간에 할당을 계속 진행하다 보면 겹치는 로케이션이 생긴다. 그때 사용자가 WMS 파일에 '주의' 열을 넣어 표시한다.
평소에는 이 열 없이 올리고, 행사 기간에만 넣는다.

## 확정 사항 (사용자 답변)
- 헤더 `주의`, 값은 `주의` 또는 빈칸. (그 밖의 글자도 주의로 처리하고 업로드 화면에 그 값을 알려줌)
- 표시 위치: **동별 수량 작성 화면만**. 최종 다운로드(WMS 업로드 양식)는 그대로.
  - 카드: 상품명 줄 오른쪽 빈 곳에 빨간 '⚠️ 주의'
  - 표: 마지막 열 '주의'에 빨간 굵은 글씨
- DB: `alloc_row.caution BOOLEAN NOT NULL DEFAULT FALSE` 추가 — 백업 후 적용 승인.

## 구현
- `migration_alloc_caution.sql` (롤백: DROP COLUMN)
- `app.py`
  - `ALLOC_CAUTION_COL`, `alloc_caution_of()` — 선택 열, 없으면 전부 FALSE
  - 업로드: 주의 행 수 안내, 신규 행 INSERT에 caution, 같은 작업에 합칠 때(같은 관리번호·상품코드·로케이션)
    기존 주의 OR 새 주의 — 2차 평소 파일이 1차 주의 표시를 지우지 않음
  - 작성 화면: 동의 주의 건수 상단 경고, 표 마지막 열(Styler 빨간 글씨, 수정 불가 열), 카드 상품명 옆 배지

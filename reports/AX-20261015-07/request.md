UPH 다운로드 매크로 자동 복구: WMS 페이지 새로고침 (사용자 요청 — 알림 대신 "스스로 새로고침해서 재시작할 수 없는지").
대상: "UPH 시스템/uph_download_macro.py" (저장소 ENCLU-LMS-LocalVersion). 운영 중인 매크로는 재시작 전까지 반영 안 됨.
배경: 2026-10-15 10:20~13:3x 다운로드(F6) 후 팝업3(SweetAlert 문구 입력 #swal2-input)이 45초 내 안 떠서 회차마다 3회 재시도 후 실패가 반복됨(간헐적으로 11:04·11:07 성공). 같은 탭을 계속 재사용하며 현재 코드엔 페이지 새로고침(driver.refresh)이 전혀 없음. run_forever docstring: 로그인 보안코드 때문에 URL로 새로 접속하지 않고 사람이 로그인해 둔 디버그 크롬 탭(9222)을 재사용.
요구:
1. 회차가 (세션 끊김이 아닌) 오류로 실패했거나, 마지막 성공 후 15분이 지나도록 성공이 없으면, 다음 회차 시작 전에 현재 WMS 탭을 driver.refresh()로 새로고침하고 페이지 준비를 기다린 뒤 진행 (URL 새 접속 아님 — 로그인 유지 전제).
2. 새로고침 후 로그인 화면이 보이면(세션 만료) 명확한 [ERR] 로그로 사람 조치 필요를 알리고 무한 새로고침 금지(간격·횟수 제한).
3. 새로고침이 효과가 있었는지 측정할 수 있게 로그(새로고침 시각, 직후 회차 성공 여부).
4. 정상 동작(연속 성공) 시 새로고침 없음 — 기존 흐름·부하 불변.
5. 세션 끊김 복구(_is_dead_session_error 경로)·재확인 회차 로직과 충돌하지 않게.
6. 테스트: 실제 브라우저·WMS 없이 driver를 가짜로 바꿔 판단 로직 검증(실패 후 새로고침, 15분 규칙, 연속 성공 시 미실행, 로그인 화면 감지 시 중단/제한).
run_forever 루프 구조와 예외 경로(현재 줄 번호)를 확인해서 최소 변경 지점을 제안해 줘.

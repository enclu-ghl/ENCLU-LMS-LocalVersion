# AX-20261023-06 — 웹앱 라이트 모드 글자·버튼 깨짐 수정 + UI 점검 (Claude 직접)

## 증상 (사용자 신고)
- 다크 모드는 정상, 기본(라이트) 모드에서 글자·버튼이 깨져 보임.

## 원인 (브라우저 실측)
- 앱 색(app.py의 `C`)은 사이드바 버튼(`st.session_state.theme`)으로 바뀌지만, Streamlit 기본 부품(표·날짜칸·선택 상자 화살표·숫자 +/-·아이콘 버튼·라디오)은 실행 중 색을 바꿀 수 없고 기기(OS/브라우저) 설정을 따른다.
- 기기가 다크 + 앱이 라이트(기본값)일 때 검은 부품이 흰 화면에 섞임 — 재고할당 작업목록 표가 검게, 비품 등록의 날짜칸·선택 화살표가 검게 나오는 것을 확인.

## 수정
1. `app.py`: `DARK = st.context.theme.type == "dark"` — 앱 색도 기기 설정을 따름. 라이트/다크 버튼 제거, 현재 모드 안내 문구로 대체.
2. `.streamlit/config.toml`(신규): `[theme.light]`/`[theme.dark]`에 앱 팔레트와 같은 배경·글자·테두리·표 머리글 색 지정. `[client] toolbarMode = "minimal"`로 Deploy 등 개발 메뉴 숨김.
3. `app.py` CSS: 다운로드 버튼(`.stDownloadButton`, 16곳)에 일반 버튼과 같은 스타일 적용 — 다크에서 기본 강조색 위 흰 글자 대비 2.99로 낮았음.
4. `app.py`: `initial_sidebar_state="auto"` — 휴대폰에서 사이드바가 펼친 채 시작해 본문을 가리던 문제.

## 검증
- 별도 테스트 서버(127.0.0.1:8502, 운영 8501과 분리)에서 기기 라이트/다크 각각 6개 시스템 25개 메뉴 + 허브를 자동 순회, 글자 대비 3:1 미만·예외 검사 → 수정 후 전부 통과 (다크 1건 발견 → 3번 수정 후 통과)
- 휴대폰 크기(375px)에서 허브·재고조사 화면 확인
- `py -B -m unittest discover -s tests` 통과
- 미검증: 실제 직원 휴대폰(삼성 인터넷의 강제 다크 등), 운영 서버 재시작 후 반영

# AX-20261023-01 — 검토 검증 (Claude)

## 변경 요약 (`UPH 시스템/uph_control_panel.py`)
- `StallMonitor`: 매크로 실행 중 이번 실행의 마지막 `[DONE]`(없으면 시작)부터 35분(`UPH_ALERT_NO_DONE_MIN`, 최소 10) 넘으면 1회 알림, 새 `[DONE]`이면 회복. 시작 시각이 바뀌면 새 실행으로 초기화.
- `[DONE]` 판정은 시작 시점 로그 크기 이후 바이트만 본다(누적 로그의 과거 완료 무시). 화면 로그 표시는 기존대로.
- 예상치 못한 종료 즉시 알림, 프로세스가 다시 돌면 해당 경고 해제. 경고는 원인별(`exit:<스크립트>`, `stall`)로 따로 관리.
- 알림: 빨간 알림 줄·최상단 창·벨·`uph_panel_events.log`·선택 웹훅(`UPH_ALERT_WEBHOOK_URL`, https만).
- 설정은 환경변수 우선, 단독 실행 시 옆 `.env`(공통 `_setting`).

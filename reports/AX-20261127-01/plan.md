| 우선순위 권한 | 지금은 막지 않음(누구나 변경 가능, 활동 기록에 남김). 계정 생성 후 팀장 역할로 제한 |

## DB (운영 적용은 사용자 승인 + pg_dump 백업 후, `migration.sql`)
새 표 4개. 기존 표는 건드리지 않는다.

- `wp_member` — 팀원
  - `id`, `name TEXT UNIQUE NOT NULL`, `is_leader BOOL DEFAULT FALSE`, `active BOOL DEFAULT TRUE`, `sort_order INT`, `created_at`
- `wp_task` — 할일 (한 주에 속함)
  - `id`, `week_start DATE NOT NULL` (월요일만 — CHECK `extract(isodow from week_start)=1`)
  - `scope TEXT CHECK IN ('팀','개인')` — 팀장이 쓰는 팀 전체 할일 / 각자 할일
  - `title TEXT NOT NULL`, `memo TEXT`
  - `owner TEXT` — 담당자 이름(팀 할일은 비워 둘 수 있음)
  - `priority SMALLINT` — 1 긴급 · 2 높음 · 3 보통 · 4 낮음, NULL = 미지정(팀장 지정 전)
  - `manual_done BOOL DEFAULT FALSE` — 체크리스트가 없는 할일의 완료 표시
  - `carried_from_id` / `carried_to_id` (자기 참조, 이월 연결)
  - `created_by`, `created_at`, `updated_at`, `deleted_at` (삭제는 숨김 처리 — 기록 보존)
- `wp_check_item` — 체크리스트 세부 항목
  - `id`, `task_id FK → wp_task ON DELETE CASCADE`, `content TEXT NOT NULL`, `sort_order`
  - `is_done BOOL DEFAULT FALSE`, `done_by TEXT`, `done_at TIMESTAMPTZ`, `created_by`, `created_at`
- `wp_activity` — 누가 언제 무엇을 했는지 (우선순위 변경·체크·삭제·이월)
  - `id`, `at TIMESTAMPTZ DEFAULT now()`, `actor TEXT NOT NULL`, `action TEXT`, `task_id`, `detail JSONB`

## 계산 규칙 (`weekly_logic.py`, 화면과 분리해 단위 테스트)
- 할일 진행률 = 체크된 항목 ÷ 전체 항목. 항목이 없으면 `manual_done`이면 100%, 아니면 0%.
- 할일 완료 = 진행률 100%.
- **주간 달성률(팀/개인) = 체크된 항목 합 ÷ 전체 항목 합** (사용자 결정: 항목 수 기준).
  체크리스트 없는 할일은 항목 1개로 친다(완료 표시 = 체크 1개).
- 이월된 원본 할일은 지난주 달성률에 미완료 그대로 남는다(기록 보존). 이번 주에는 새 할일로 들어간다.
- 이월: 원본 할일을 다음 주에 복사(제목·메모·담당·우선순위), **체크 안 된 항목만** 복사. 원본에 `carried_to_id`, 사본에 `carried_from_id`. 같은 할일 두 번 이월 금지.
- 주 시작일 계산은 KST 기준 월요일.

## 화면 (사이드바 메뉴)
상단 공통: 주 선택(◀ 지난주 · 이번 주 · 다음 주 ▶, 날짜 범위 표시), "나: [팀원 선택]".
1. **📅 이번 주 계획** — 팀 달성률·완료 할일 수 요약 → 할일 카드 목록(우선순위 순: 긴급→낮음→미지정, 같은 순위는 정렬값)
   - 카드: 우선순위 배지, 팀/개인, 담당, 진행률 막대, 체크리스트(바로 체크 — 체크한 사람·시각 기록)
   - 필터: 전체 / 팀 할일 / 담당자별 / 미완료만
   - 지난주 미완료가 있으면 "지난주 미완료 N건 이월하기" 펼침 → 골라서 이월
2. **✍️ 할일 작성** — 팀/개인, 제목, 담당, 우선순위, 메모, 체크리스트 항목(여러 줄 입력 → 한 줄 = 한 항목). 기존 할일 수정·항목 추가/삭제·할일 삭제(숨김)
3. **🎯 우선순위 정리** — 이번 주 할일 표에서 우선순위·순서를 한 번에 수정(팀장 용도, 지금은 누구나 가능 + 활동 기록)
4. **📊 달성률** — 주별 팀 달성률 추이, 팀원별 달성률, 주간 완료 목록, 엑셀 내려받기
5. **⚙️ 팀원 관리** — 팀원 추가·이름 변경·비활성화·팀장 표시. 활동 기록 보기

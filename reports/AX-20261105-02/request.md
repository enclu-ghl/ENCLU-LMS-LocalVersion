# AX-20261105-02 요청 — 비품·소모품·포장재 분리, 제작 박스 관리, 소모품·포장재 분석 개편

## 현재 (2026-11-05, 운영 DB 조회)
- 웹앱 "비품/소모품 관리" 시스템(app.py): 메뉴 "📝 비품/소모품 등록", "📦 비품 리스트", "🧰 소모품 리스트", "🔄 소모품 주기 체크", "📊 소모품 분석 · 발주".
- 표: equipment_items 1행, supply_items 0행, supply_check 0행, supply_receipt 0행(사실상 미사용 — 지금 구조를 바꾸기 좋은 시점).
  supply_check.item_id·supply_receipt.item_id → supply_items(id) FK.
- 주기 체크: 남은 수량 입력 → 직전 체크·그 사이 입고(supply_receipt)로 사용량·기간 계산(`supply_consumption_stats`, `supply_days_left`).
- 무게구간 시스템의 "⚖️ 포장재 관리" = `packaging_materials`(23행: name UNIQUE, real_weight_g, length/width/height_cm). 무게 계산(`weight_calc_results.packaging_name`)이 이름으로 참조.

## 사용자 요구 (2026-11-05)
1. 등록을 **비품 / 소모품 / 포장재** 세 가지로 나눈다.
2. **포장재는 무게구간의 `packaging_materials`와 같은 품목 — 연결**한다(한 품목에 무게·크기와 재고·주기 체크가 함께 붙게). 중복 등록이 생기지 않게.
3. **제작 완료 박스 관리 페이지** 신설 — 박스를 직접 제작해 보관 중. 단순 재고·제작 확인용 참고 페이지.
   항목: 박스명, 파렛트 수량, 위치, 최소 재고선(파렛트 기준) + 제작 기록(언제 몇 파렛트 제작).
4. **주기 체크는 소모품과 포장재**를 대상으로 한다(비품·제작 박스는 제외).
5. **분석을 소모품과 포장재로 나눈다.** 그리고
   - 주기 체크·수정을 하는 그 자리에서 해당 품목의 분석이 바로 보이면 좋다.
   - 여러 품목을 선택해 한 번에 비교해 볼 수 있으면 좋다.
   - 소모품·포장재 각각 **전체 품목별 발주 주기**를 볼 수 있으면 좋다: **실제 발주 간격(입고 기록 사이 평균 일수)과 사용량 기준 권장 주기를 둘 다** 표시.

## 제약
- 메뉴 문자열은 기존 것을 바꾸지 않는 것이 원칙(허브·바로가기·기억된 메뉴가 문자열에 의존). 바꿔야 하면 지시서에 영향 범위와 함께 명시해 사용자 확인.
- 운영 DB 스키마 변경은 백업 후, 시험 실행(ROLLBACK) 후 적용. 표 소유자는 `enclu_app`. 무게구간 화면·계산(`packaging_materials` 사용처)이 깨지지 않아야 한다.
- 계정은 아직 없음 — 기록자는 이름 입력(기존 checker 방식).
- 대량 쓰기는 일괄 처리. Streamlit 1.64.

## 지시서에 필요한 것
데이터 모델(품목 구분 방식, packaging_materials 연결 방식, 제작 박스 표·제작 기록 표 DDL), 메뉴·화면 구성, 분석 산식(기간·단위·분모·제외 조건), 기존 데이터 이전(현재 거의 0행), 테스트 계획, 롤백.

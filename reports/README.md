# reports/

작업번호(`AX-YYYYMMDD-NN`)별 폴더에 아래 파일을 남긴다.

| 파일 | 작성 | 내용 |
|---|---|---|
| `plan.md` | Codex (`ax\codex-plan.ps1`) | 작업 지시서 |
| `plan-check.md` | Claude | 지시서 검증: 수용/수정/거부 + 근거 |
| `review.md` | Codex (`ax\codex-review.ps1`) | 변경 검토 |
| `review-check.md` | Claude | 검토 검증: 타당/부분 타당/근거 없음 + 근거, 실행한 테스트 |

공개 저장소이므로 업무 원본 데이터·비밀값·IP는 넣지 않는다.
